隐私政策

本政策分别说明游戏本地数据、自愿发送的客服邮件，以及本网站托管涉及的数据。

2026-10-25

游戏数据保存在本地

游戏无需账户，不包含广告、跟踪或分析 SDK，也没有开发者运营的数据服务。我们不收集游戏进度或将其发送至服务器。存档、语言与声音偏好使用设备本地存储保存。

自愿发送的客服邮件

联系 wlh96110@gmail.com 时，我们会收到你的邮箱地址、邮件内容及自愿附上的附件，并用于处理你的请求。请勿附上客服处理不需要的敏感信息。可通过同一地址申请删除这些通信内容。

购买与 Apple 服务

App Store 交易由 Apple 处理，我们不接收你的银行卡资料。Apple 可能依照其设置和隐私政策处理购买信息、诊断数据或设备备份。本地游戏数据可能包含在 Apple 管理的设备备份中。

网站数据

本静态网站不添加分析工具、广告跟踪器、Cookie 或联系表单。本网站由 GitHub Pages 托管。GitHub 为安全目的记录访问者 IP 地址。此类托管记录与游戏数据分开，由 GitHub 按其隐私政策处理。

你的选择

可删除应用以移除设备本地数据，并在 Apple 设置中管理设备备份。有关客服邮件或隐私问题，请联系 wlh96110@gmail.com。本游戏没有需要另外删除的开发者服务器账户或云端存档。

托管参考

GitHub Pages 数据收集说明：https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection · GitHub 隐私声明：https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement

政策更新

政策日期：2026 年 10 月 25 日。若游戏或托管方式改变，我们会更新此页面，说明新的数据处理方式。
