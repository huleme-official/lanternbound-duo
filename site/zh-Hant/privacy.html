隱私權政策

本政策分別說明遊戲本機資料、自願傳送的客服郵件，以及本網站託管涉及的資料。

2026-10-25

遊戲資料儲存在本機

遊戲無需帳號，不包含廣告、追蹤或分析 SDK，也沒有開發者營運的資料服務。我們不收集遊戲進度，也不將其傳送至伺服器。存檔、語言與聲音偏好使用裝置本機儲存空間保存。

自願寄送的客服郵件

聯絡 wlh96110@gmail.com 時，我們會收到你的信箱地址、郵件內容及自願附上的附件，並用於處理你的請求。請勿附上客服處理不需要的敏感資訊。可透過同一地址申請刪除這些通訊內容。

購買與 Apple 服務

App Store 交易由 Apple 處理，我們不接收你的付款卡片資料。Apple 可能依照其設定及隱私權政策處理購買資訊、診斷資料或裝置備份。本機遊戲資料可能包含在 Apple 管理的裝置備份中。

網站資料

本靜態網站不加入分析工具、廣告追蹤器、Cookie 或聯絡表單。本網站由 GitHub Pages 託管。GitHub 基於安全目的記錄訪客 IP 位址。這類託管紀錄與遊戲資料分開，由 GitHub 按其隱私權政策處理。

你的選擇

可刪除 App 以移除裝置本機資料，並在 Apple 設定中管理裝置備份。客服郵件或隱私問題請聯絡 wlh96110@gmail.com。本遊戲沒有需要另外刪除的開發者伺服器帳號或雲端存檔。

託管參考
