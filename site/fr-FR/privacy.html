Confidentialité

Cette politique distingue les données locales du jeu, les courriels d’assistance facultatifs et l’hébergement du site.

2026-10-25

Données locales du jeu

Aucun compte n’est requis. Le jeu ne contient ni publicité, ni suivi, ni SDK d’analyse, ni service de données exploité par le développeur. Nous ne recueillons pas votre progression et ne l’envoyons pas sur nos serveurs. Progression, langue et son sont enregistrés localement.

Courriels facultatifs

Un message à wlh96110@gmail.com nous transmet votre adresse, votre texte et les pièces jointes choisies. Nous les utilisons pour répondre à votre demande. Évitez les informations sensibles inutiles ; vous pouvez demander la suppression des échanges à cette même adresse.

Apple et les achats

Apple gère les transactions App Store. Nous ne recevons pas vos coordonnées de carte bancaire. Les achats, diagnostics et sauvegardes gérés par Apple dépendent de ses réglages et politiques. Les données locales du jeu peuvent figurer dans une sauvegarde de l’appareil.

Données du site

Ce site statique n’ajoute aucun outil d’analyse, traceur publicitaire, cookie ou formulaire de contact. Ce site est hébergé sur GitHub Pages. GitHub enregistre les adresses IP des visiteurs à des fins de sécurité, séparément des données du jeu et selon sa propre politique.

Vos choix

Supprimez l’app pour retirer ses données locales et gérez vos sauvegardes dans les réglages Apple. Questions ou suppression des courriels : wlh96110@gmail.com. Il n’existe aucun compte ni sauvegarde cloud sur un serveur du développeur à supprimer.

Informations sur l’hébergement

Collecte GitHub Pages : https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection · Politique GitHub : https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement
